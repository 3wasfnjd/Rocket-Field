# ميدان الصواريخ — Rocket Field

لعبة حرب فرق في Roblox من **عبودين قيمز**، مبنية على قالب Laser Tag الرسمي من Roblox، وصواريخها من فكرة **حرب الطاولة** (AR-Aboden/table-war).

## الفكرة
- **فريقين:** الوردي والأخضر، ولكل فريق **معسكر**: ثكنة (غرفة الظهور من مبنى القالب)، وبرجين مراقبة، وأكياس رمل، وخيام، وبراميل وقود، وعلم، وصناديق.
- **السلاح الشخصي:** بلاستر الليزر والرشاش من القالب نفسه.
- **محطة الصواريخ:** كمبيوتر على طاولة جنب كل ثكنة، ومنصة إطلاق. افتح الكمبيوتر (لفريقك بس)، وتشوف معسكر العدو من فوق. اضغط على الهدف، واختر الصاروخ، واضغط «إطلاق». المنصة والكمبيوتر **ما يتأثرون بالانفجارات**.
- **المضادات الأرضية:** 3 رشاشات بمقعد في كل معسكر. تجلس، وتصوّب، وتضغط مطوّل، وتسقط صواريخ العدو قبل ما توصل. كل صاروخ له «صلابة»: الفرط صوتي صعب مرة، والراجمة تطيح بسرعة.
- **الإنذار:** لما العدو يطلق، تطلع دائرة حمرا مكان السقوط، وفريقك يجيه إنذار، والصواريخ يبين فوقها علامة ▼ في السما.
- **الفوز:** نتيجة كل فريق = **نسبة تدميره لمعسكر العدو**. اللي يدمّر 100% يفوز على طول، وإلا بعد 8 دقايق يفوز صاحب النسبة الأعلى.

## الصواريخ (من الكمبيوتر)
| الصاروخ | الطريقة | ملاحظات |
|---|---|---|
| باليستي | قوس عالي، انفجار كبير | انتظار 20ث |
| كروز | يطير منخفض فوق الأرض وينقضّ | ممكن يصطدم بالأبراج |
| راجمة | 8 صواريخ حول الهدف | كل واحد يطيح بطلقتين مضاد |
| عنقودي | ينفتح قبل الهدف إلى 10 قنيبلات | |
| فرط صوتي | سريع جداً | انتظار 60ث، صعب يطيح |
| خارق التحصينات | ضرر ضخم على المباني | |
| مسيّرة انتحارية | بطيئة وتتمايل | أسهل هدف للمضاد |

البراميل الحمرا تنفجر لما تنضرب، والانفجار يحفر الأرض (إلا تحت المحطة والمضادات).

**التحكم:** الكمبيوتر بالماوس (اسحب لتحريك الخريطة، والعجلة للتقريب). الجوال: اسحب بإصبعك واضغط على الهدف. والمضاد: الماوس أو زر «ضرب».

## المشروع
| المسار | المحتوى |
|---|---|
| `base/LaserTag-Template.rbxlx` | قالب Laser Tag كما هو |
| `src/shared/Weapons.luau` | جدول الصواريخ وحساب القوس |
| `src/server/World.luau` | الأرض والحفر ومواقع المحطة والمضادات |
| `src/server/Camps.luau` | المعسكرات القابلة للتدمير ونسبة كل فريق |
| `src/server/Missiles.luau` | طيران الصواريخ والانفجار والضرر |
| `src/server/Station.luau` | الكمبيوتر ومنصة الإطلاق وفترات الانتظار |
| `src/server/AntiAir.luau` | المضادات الأرضية |
| `src/client/` | شاشة الكمبيوتر، المضاد، الإنذار، عدّاد المعسكرات |
| `tools/build_place.py` | يقص مبنى القالب، ويعدّل نقاط القالب (`tools/patches/TDM.luau`)، ويدمج السكربتات ← `RocketField.rbxlx` |
